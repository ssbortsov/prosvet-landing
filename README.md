# Просвет — лендинг

Лендинг образовательной экосистемы «Просвет». Вёрстка по макету Figma «Просвещение» → «лендинг — бенто».

Статический сайт: один `index.html` (HTML + CSS + JS без сборки и зависимостей) и папка `assets` с логотипом, фоном и иллюстрациями. Шрифт Inter подключается с Google Fonts.

## Структура

```
index.html        разметка, стили и скрипты
assets/
  logo.svg        логотип
  hero-glow.svg   фирменный градиент (фиксированный фон страницы)
  curve.svg       кривая блока истории (в странице используется inline-версия)
  *.webp          иллюстрации
.nojekyll         отключает обработку Jekyll на GitHub Pages
```

## Запуск локально

Откройте `index.html` в браузере или поднимите локальный сервер:

```
python3 -m http.server 8000
```

и перейдите на http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки (файлы должны лежать в корне).
2. Settings → Pages → Build and deployment → Source: Deploy from a branch.
3. Выберите ветку `main` и папку `/ (root)`, сохраните.

Через минуту сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

## Сценарии на странице

- Первый экран: белый старт с пятном градиента за иллюстрацией → при скролле градиент заливает экран, текст инвертируется, снизу выезжает белая плашка.
- Второй экран выезжает поверх первого, плашка раскрывается до краёв; кривая между 1930 и 2026 рисуется по скроллу, блоки с датами проявляются.
- Компании: секция закрепляется на весь экран, вертикальный скролл двигает ленту карточек по горизонтали (на мобильных — обычная лента со свайпом).
- Проекты: карточки прилипают под шапкой и наслаиваются, следующая выезжает с поворотом.
- Принципы бренда — сетка из четырёх карточек.
- Финал: синий фон сворачивается в круг вокруг иллюстрации, внизу футер.

При включённом в системе «уменьшении движения» анимации отключаются, контент показывается статично.

## Что осталось заполнить

- Логотипы компаний (сейчас заглушки «логотип») и ссылки карточек компаний (`href="#"`).
- Фото / визуалы проектов при необходимости заменить иллюстрации.
